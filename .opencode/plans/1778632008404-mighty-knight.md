## Implementation Approach

- Add an internal sink-oriented decompression path without changing the public extraction API.
- Use bounded streaming only for LZ4 frame payloads, because the current official LZ4 frame adapter supports incremental input/output.
- Keep deflate and raw LZ4 block as explicit whole-buffer fallbacks, but validate decoded sizes before allocation and write decoded output through existing exact sink helpers.
- Keep TES4 BSA, BA2 GNRL, and BA2 DX10 readers responsible for their existing format-specific validation before calling the compression router.
- Add `archive_reader::extract_bytes` preflight so impossible single-vector outputs fail before payload I/O or decompression.
- Mark each OpenSpec checkbox in `openspec/changes/bound-compressed-extraction-memory/tasks.md` immediately after its implementation or verification step succeeds.

## Detailed Steps

1. Add internal declarations and docs.

- Add `decompress_lz4_frame_exact_to_sink(...)` to `src/detail/lz4_frame_codec.hpp` with Doxygen comments describing exact-size validation, bounded chunks, and possible partial sink output before malformed input is detected.
- Add `decompress_payload_exact_to_sink(...)` to `src/detail/compression_router.hpp` with Doxygen comments describing LZ4 frame streaming versus whole-buffer fallback methods.
- Add or extend a helper in `src/detail/payload_stream.*` for single-vector materialization preflight, likely `checked_materialized_payload_size(std::uint64_t, std::string_view)`, using both `std::size_t` range and `std::vector<std::byte>{}.max_size()`.

2. Implement LZ4 frame exact-to-sink streaming.

- In `src/detail/lz4_frame_codec.cpp`, create an `LZ4F_dctx` as the current whole-buffer decoder does.
- Validate the compressed archive range with `validate_payload_stream_range` before seeking.
- Read compressed input from `std::ifstream` into a bounded scratch buffer, using the caller-provided chunk size.
- Decompress via `LZ4F_decompress` into a bounded output scratch buffer.
- Track total decoded bytes as `std::uint64_t` and reject output that would exceed `expected_size` before writing beyond the declared output size.
- Write produced bytes with `detail::write_payload_exact` so partial sink acceptance remains `error_code::io_error`.
- Return `format_error` for LZ4 errors, truncated compressed ranges, too few decoded bytes, too many decoded bytes, unfinished frames, unconsumed compressed bytes, and zero-consume/zero-produce progress loops.

3. Add router sink support.

- In `src/detail/compression_router.cpp`, route `compression_method::lz4_frame` to `decompress_lz4_frame_exact_to_sink`.
- For `compression_method::deflate` and `compression_method::lz4_block`, call the new materialization preflight before reading stored bytes or invoking existing whole-buffer decoders.
- Read fallback stored payloads with `read_payload_bytes_at`, decode with `decompress_payload_exact`, and write decoded bytes with `write_payload_chunks`.
- Preserve unsupported enum handling as `error_code::invalid_argument`.
- Keep `compression_method::none` exact-size behavior unchanged for the existing whole-buffer vector API. The sink router can either reject `none` as an invalid decompression path or copy through exact sink writes only if a reader needs it; current readers should continue using raw streaming paths instead.

4. Integrate TES4 BSA extraction.

- In `src/formats/bsa/tes4_bsa_reader.cpp`, preserve embedded-name prefix validation and raw streaming for uncompressed entries.
- Preserve compressed size-prefix read and prefix-vs-`entry.raw_size` validation before routing.
- Replace full compressed payload read plus `decompress_payload_exact` with `decompress_payload_exact_to_sink` over the compressed range after the 4-byte prefix.
- Keep the existing overflow checks for consumer payload offset and compressed payload offset.

5. Integrate BA2 GNRL extraction.

- In `src/formats/ba2/ba2_gnrl_reader.cpp`, preserve embedded-name rejection, raw streaming, and compression method validation.
- Replace stored payload materialization plus whole-buffer decode with `decompress_payload_exact_to_sink` for compressed entries.
- Preserve existing `format_error` behavior for raw entries entering decompression and unsupported LZ4 frame metadata.

6. Integrate BA2 DX10 chunk extraction.

- In `src/formats/ba2/ba2_dx10_reader.cpp`, preserve texture metadata checks and embedded-name rejection.
- Preserve DDS DXT10 header emission before opening/processing chunk payloads.
- Preserve raw chunk streaming and parser-validated chunk order comments.
- Replace compressed chunk materialization plus whole-buffer decode with `decompress_payload_exact_to_sink` per chunk.
- Ensure a malformed chunk fails immediately and later chunks are not extracted.

7. Add `extract_bytes` preflight.

- In `src/archive.cpp`, run the new materialization preflight after successful `find(path)` and before constructing `vector_payload_sink` or calling `extract_entry_payload`.
- Keep invalid path behavior from `find(path)` as `invalid_argument`.
- Keep missing path behavior as `not_found`.
- Keep ordinary allocation failures translated through the existing `vector_payload_sink` path for representable sizes that still cannot reserve at runtime.

8. Add focused tests.

- Extend `tests/unit/lz4_codec_tests.cpp` with exact-to-sink LZ4 frame tests for bounded write chunk sizes, truncated frame input, exact-size mismatch, and no write beyond declared output size.
- Extend `tests/unit/compression_router_tests.cpp` with sink-router tests proving LZ4 frame streaming works and unsupported enum behavior remains stable.
- Extend `tests/unit/payload_stream_tests.cpp` for the new materialization preflight helper.
