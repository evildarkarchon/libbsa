## Implementation Steps

1. Add policy coverage for snapshot-directory hardening.
   - Extend `tests/unit/bounded_memory_policy_tests.cpp` with a focused source-policy test for `src/formats/ba2/ba2_dx10_prepare.cpp`.
   - Assert the implementation uses `BCryptGenRandom`, `BCRYPT_USE_SYSTEM_PREFERRED_RNG`, `std::filesystem::create_directory`, and the `libbsa-dx10-snapshot-` prefix.
   - Assert old counter-only markers are absent: `static std::atomic_uint64_t counter`, `fetch_add`, and `std::to_string(id)`.

2. Add writer cleanup coverage.
   - Extend `tests/unit/ba2_dx10_writer_tests.cpp` with a scoped `ba2_dx10_writer` test that stages a valid DDS source.
   - Record existing temp directories matching `libbsa-dx10-snapshot-*` before staging.
   - While the writer is alive, identify newly created matching directories and assert at least one exists.
   - After writer teardown, assert each newly observed directory has been removed by best-effort `ba2_dx10_writer::state` cleanup.
   - Leave existing BA2 DX10 fixture, round-trip, compression, metadata, extraction, and validation expectations unchanged.

3. Harden snapshot directory reservation.
   - In `src/formats/ba2/ba2_dx10_prepare.cpp`, remove the static atomic counter include/use.
   - Add Windows RNG support with `<bcrypt.h>`.
   - Add a private helper that requests 16 fresh random bytes per candidate with `BCryptGenRandom(nullptr, ..., BCRYPT_USE_SYSTEM_PREFERRED_RNG)`.
   - Treat RNG failure as `libbsa::error_code::io_error` with a BA2 DX10 snapshot reservation message.
   - Hex-encode the 16 random bytes into a 32-character lowercase ASCII suffix.
   - Keep candidate names shaped as `libbsa-dx10-snapshot-<hex-suffix>`.
   - Keep the existing bounded retry count of 1024 attempts.
   - Accept a candidate only after `std::filesystem::create_directory(candidate, fs_error)` succeeds.
   - On collision (`create_directory` false with no `fs_error`), retry with fresh random bytes.
   - On filesystem reservation error or retry exhaustion, return `io_error` without staging an entry.
   - Keep `ba2_dx10_writer::state` cleanup ownership unchanged.

4. Add private system linkage.
   - Add `bcrypt` to `target_link_libraries(libbsa PRIVATE ...)` in `CMakeLists.txt`.
   - Mirror `bcrypt` in `tests/CMakeLists.txt` inside `libbsa_link_internal_test_support()` for shared-build test targets that compile libbsa sources directly.

5. Mark OpenSpec tasks complete as implementation progresses.
   - Update `openspec/changes/harden-dx10-snapshot-temp-dirs/tasks.md` checkboxes immediately after completing each corresponding task group.
   - Do not mark verification tasks until the relevant command has completed successfully.

## Notes From Microsoft Documentation

- `BCryptGenRandom` is declared in `bcrypt.h` and uses `Bcrypt.lib` for desktop user-mode callers.
- `BCRYPT_USE_SYSTEM_PREFERRED_RNG` requires `hAlgorithm == nullptr` and returns an `NTSTATUS` success/failure code.
