## Implementation Order

1. Update consumer-facing documentation.
   - Edit `docs/target-format-guide.md` under/near `## writer target policies` to add writer output publication safety guidance.
   - Cover same-directory writer-owned temporary publication, same-volume expectation for normal local paths, no-overwrite failure when the destination exists, overwrite intended only for existing regular files, detectable Windows reparse-point refusal, network/reparse-provider caveats, and `io_error` publish failures.
   - Update `include/libbsa/writer.hpp` Doxygen comments for `overwrite_existing` options and/or `write_to` methods so public API readers see the same contract without implementation details.

2. Add shared publish-helper policy.
   - Edit only `src/detail/writer_publish.cpp` for the new helper logic; keep Win32 details private and do not expose Win32 types in public headers.
   - Add a private `path_is_reparse_point_noexcept(...)` helper in the anonymous namespace using `GetFileAttributesW` and `FILE_ATTRIBUTE_REPARSE_POINT` under `#if defined(_WIN32)`.
   - Treat missing paths during a race as not reparse-point failures so existing overwrite behavior for disappearing destinations is preserved; return prefixed `io_error` for true attribute-inspection failures.
   - In `validate_writer_output_path_before_publish`, when `overwrite_existing` is enabled and the destination exists, reject detectable reparse points before the existing `std::filesystem::is_regular_file` check.
   - In `publish_completed_writer_output`, add a final reparse-point check immediately before `replace_file_atomically` so a destination swapped after validation is refused before publication.
   - Preserve current no-overwrite behavior, regular-file overwrite success, writer-specific diagnostic prefixes, and best-effort temp-directory cleanup paths.

3. Extend focused regression tests.
   - Update `tests/unit/writer_publish_tests.cpp` with helper-level coverage for read-only existing destination failure: create an existing file, make it read-only, attempt overwrite, assert `io_error`, assert writer diagnostic prefix, assert original bytes remain, and restore writability before cleanup.
   - Add conditional Windows reparse-point tests in `tests/unit/writer_publish_tests.cpp`: create a file symlink or other reparse point when the host allows it, skip/warn cleanly if unavailable, then assert publish refusal, original target bytes, reparse-point existence, and temp cleanup.
   - Include a raced-reparse case if practical: start with a free output path, create the reparse point from inside the write callback, and assert the final pre-publication check prevents replacement.
   - Keep existing directory-target helper coverage and add only missing writer-family directory coverage required by task 3.3, likely `tes3_bsa_writer_tests.cpp` and `tes4_bsa_writer_tests.cpp`; BA2 GNRL and BA2 DX10 already cover existing directories.
   - Update `tests/unit/target_format_policy_tests.cpp` to require the new target-format guide terms: same-directory temporary output, `overwrite_existing`, regular file, reparse point, network filesystem, and `io_error`.

4. Mark OpenSpec tasks as completed as each implementation slice passes local checks.
