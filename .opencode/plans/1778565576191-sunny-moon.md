## Goal

Centralize duplicated extraction I/O mechanics in `src/detail/payload_stream.*` and refactor TES4 BSA, BA2 GNRL, and BA2 DX10 extraction readers to use those helpers while preserving format-specific behavior in each reader.

## Files To Modify

- `src/detail/payload_stream.hpp`
- `src/detail/payload_stream.cpp`
- `tests/unit/payload_stream_tests.cpp`
- `src/formats/bsa/tes4_bsa_reader.cpp`
- `src/formats/ba2/ba2_gnrl_reader.cpp`
- `src/formats/ba2/ba2_dx10_reader.cpp`
- `tests/unit/bulk_extraction_tests.cpp`, only if its source-policy assertions need adjustment after helper centralization
- `openspec/changes/centralize-payload-extraction-helpers/tasks.md`, to mark completed tasks as implementation progresses

## Implementation Steps

1. Extend `src/detail/payload_stream.hpp` with internal helper declarations.
   - Add checked archive-size conversion: `checked_payload_size(std::uint64_t, std::string_view)`.
   - Add stream-span validation for archive offsets/sizes.
   - Add exact sink write helper for reconstructed headers and individual chunks.
   - Add chunked span write helper for decoded payload buffers.
   - Add exact file-range read helper returning `std::vector<std::byte>`.
   - Add raw range streaming helper from `std::ifstream` to `payload_sink` using bounded scratch chunks.

2. Implement helpers in `src/detail/payload_stream.cpp`.
   - Preserve current `transfer_payload` behavior and diagnostics unless sharing private code is non-observable.
   - Use `detail::make_byte_vector` for allocation-safe archive-controlled reads.
   - Reject archive sizes that exceed `std::size_t` with `format_error`.
   - Reject offsets, sizes, and offset-plus-size spans that exceed stream limits with `format_error`.
   - Clear the stream before absolute seeks.
   - Return `io_error` for seek/read I/O failures.
   - Return `format_error` for truncated declared archive ranges.
   - Return `io_error` when a sink accepts fewer bytes than requested.
   - Preserve caller-supplied descriptions in diagnostics.

3. Expand `tests/unit/payload_stream_tests.cpp`.
   - Cover checked size conversion success and overflow rejection.
   - Cover stream-limit rejection for offset/size/span cases.
   - Cover exact reads from a temporary binary file at nonzero offsets.
   - Cover truncated exact reads.
   - Cover raw range streaming into a memory sink.
   - Cover chunked span writes with a small chunk size.
   - Cover partial sink write failures through exact and chunked helper paths.
   - Keep existing `transfer_payload` tests intact.

4. Refactor `src/formats/bsa/tes4_bsa_reader.cpp`.
   - Include `detail/payload_stream.hpp`.
   - Remove local duplicated helpers: checked size, stream-limit validation, exact write, chunked write, raw range streaming, and exact byte reads.
   - Raw uncompressed path calls shared raw range streaming helper.
   - Compressed path keeps embedded-name prefix handling and compressed-size-prefix validation local.
   - Read the 4-byte TES4 compressed-size prefix through the shared exact file read helper, then decode little-endian locally.
   - Read compressed bytes through the shared exact file read helper.
   - Write decoded bytes through the shared chunked span helper.
   - Keep TES4 compression method mapping local.

5. Refactor `src/formats/ba2/ba2_gnrl_reader.cpp`.
   - Include `detail/payload_stream.hpp`.
   - Remove local duplicated checked size, exact write, chunked write, stream-limit validation, raw streaming, and stored payload read helpers.
   - Keep embedded-name rejection local.
   - Keep raw `raw_size == stored_size` validation local.
   - Open the archive once per extraction path as the current design does, then delegate streaming or exact reads to shared helpers.
   - Keep BA2 GNRL compression routing local.
   - Write decoded bytes through the shared chunked span helper.

6. Refactor `src/formats/ba2/ba2_dx10_reader.cpp`.
   - Include `detail/payload_stream.hpp`.
   - Remove local duplicated checked size, exact write, chunked write, stream-limit validation, raw chunk streaming, and stored chunk read helpers.
   - Write the reconstructed DDS header through the shared exact sink write helper.
   - Keep DDS reconstruction, DirectXTex validation decisions, parser-provided chunk ordering, and compression routing local.
   - Keep raw chunk `raw_size == stored_size` validation local.
   - Stream raw chunks and read compressed chunks through shared helpers.
   - Write decoded chunk bytes through the shared chunked span helper.

7. Clean up reader includes and brittle source-policy tests.
   - Remove unused `<limits>`, `<vector>`, and `detail/byte_vector.hpp` includes where they become unnecessary.
   - Keep existing comments unless code they describe is removed or materially changed.
   - If `tests/unit/bulk_extraction_tests.cpp` source-text assertions fail because chunking moved into `payload_stream.cpp`, update them to assert the centralized helper policy instead of requiring every reader file to contain the chunk constant.

8. Mark tasks complete incrementally in `openspec/changes/centralize-payload-extraction-helpers/tasks.md`.
   - Update each checkbox immediately after its code/test work is complete.
   - Do not mark verification tasks complete until the relevant command has actually run.

## Risks

- Diagnostic string drift could affect tests. Mitigation: keep caller descriptions and stable error categories; tests should compare `error_code` rather than exact messages.
- Raw streaming must remain bounded and must not allocate whole payloads.
- Compressed extraction may still allocate per-entry or per-chunk codec buffers, matching current behavior.
- TES4 compressed-size prefix and BA2 DX10 DDS/header ordering must remain reader-owned to avoid format behavior regressions.
