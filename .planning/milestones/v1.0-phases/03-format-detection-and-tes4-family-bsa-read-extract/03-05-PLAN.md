| archive table bytes→entry metadata | Untrusted names, offsets, sizes, and hashes become public values. |

| payload prefix→embedded metadata | Embedded-name bytes influence public metadata and later extraction cursor. |

| T-03-03 | Tampering | canonical path map | mitigate | Normalize archive paths and fail duplicate canonical keys as `format_error`. |
| T-03-04 | Tampering | embedded-name metadata | mitigate | Validate prefix size during construction and expose it before extraction. |
| T-03-05 | Tampering | lookup inputs | mitigate | Use `normalize_archive_path`; invalid inputs return `invalid_argument`, valid missing paths return absence. |
</threat_model>
