Serialization must emit:
- Header: `BTDX`, version `1` for `fallout4` or `3` for `starfield_v3`, subtype `DX10`, file count, FileTableOffset; Starfield v3 adds `Unknown1`, `Unknown2`, `CompressionMethod`.
- Texture record: name hash, four-byte extension field, directory hash, `unknown_tex` writer-owned default, chunk count, chunk header size `24`, height, width, mip count, numeric DXGI format, `cube_maps_raw` (`2048` non-cubemap, `2049` cubemap unless current reader requires exact existing constant).
- Chunk record: payload offset, nonzero packed size for non-empty compressed chunks, raw size, start mip, end mip, sentinel `0xBAADF00D`.
- Filename table: UInt16 length-prefixed preserved archive paths at `FileTableOffset`.
</interfaces>
