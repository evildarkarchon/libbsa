Validation public contract to create:
```cpp
enum class compatibility_warning_code {
  compressed_sound_payload,
  bsa_embedded_name_compatibility_risk,
  target_family_mismatch,
};

enum class compatibility_warning_severity { advisory, risky };

struct validation_diagnostic {
  error_code code;
  std::string message;
};

struct compatibility_warning {
  compatibility_warning_code code;
  compatibility_warning_severity severity;
  std::string message;
  std::optional<std::string> archive_path;
};

struct validation_options {
  std::optional<archive_type> expected_type;
  std::optional<archive_variant> expected_variant;
  bool validate_entry_extractability{false};
};

struct validation_report {
  bool valid{false};
  std::optional<archive_metadata> metadata;
  std::vector<validation_diagnostic> errors;
  std::vector<compatibility_warning> warnings;
  [[nodiscard]] bool is_valid() const noexcept;
};

[[nodiscard]] result<validation_report> validate_archive(std::string_view host_path,
                                                         validation_options options = {});
```
</interfaces>

<decision_trace>
- D-01: The public contract declares `validate_archive(host_path, options = {}) -> result<validation_report>`.
- D-04: `validation_report` carries validity, optional metadata, fatal errors, and warnings only.
- D-05: `validation_options` is limited to expected type/variant and `validate_entry_extractability`.
- D-06: `compatibility_warning_code` is a public stable enum.
- D-07: `compatibility_warning` carries code, severity, message, and optional archive path.
- D-08: `compatibility_warning_severity` contains only `advisory` and `risky`.
- D-09: Public warning records do not expose byte offsets, record indexes, or chunk indexes.
- D-16: Public validation headers remain C++20 and dependency-light.
- D-17: Public contracts keep stable programmatic identifiers separate from human messages.
</decision_trace>
