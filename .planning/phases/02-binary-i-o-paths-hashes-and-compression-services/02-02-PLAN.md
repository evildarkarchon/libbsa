namespace libbsa::detail {
class payload_source {
 public:
  virtual ~payload_source() = default;
  virtual result<std::size_t> read(std::span<std::byte> destination) = 0;
  [[nodiscard]] virtual std::size_t remaining() const noexcept = 0;
};
class payload_sink {
 public:
  virtual ~payload_sink() = default;
  virtual result<std::size_t> write(std::span<const std::byte> bytes) = 0;
};
result<void> transfer_payload(payload_source& source, payload_sink& sink, std::size_t chunk_size);
}

<source_decision_coverage>
- D-02: `archive_path_key` is internal under `libbsa::detail`, not a public `path.hpp` type.
- D-05: Path tests and implementation fold canonical keys to lowercase.
- D-06: Path tests and implementation treat `/` and `\\` as equivalent and store `/`.
- D-07: Invalid empty, absolute, drive-rooted, dot/traversal, and empty-component paths are rejected.
- D-08: Path utilities produce canonical keys only, with display/original spelling outside this phase.
- D-09: Streaming contracts are internal and do not add public extraction or packing APIs.
- D-10: Streaming tests assert exact byte preservation and source/sink failure propagation.
- D-11: Streaming is synchronous only with no async, threading, or cancellation API.
- D-12: Tests prove multiple bounded chunks using a local test chunk size without creating a project-wide constant.
- D-13: Bounded sources and sinks use simple internal object interfaces.
- D-14: Partial sink acceptance is a structured `error_code::io_error` failure.
- D-15: Payload sources expose bounded `remaining()` so transfers stop at metadata limits.
- D-16: Tests use memory-backed test doubles and do not add file-backed extraction sinks.
</source_decision_coverage>
