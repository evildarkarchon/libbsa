<feature>
  <name>Starfield v3 BA2 GNRL compression-method routing</name>
  <files>tests/ba2_reader_tests.cpp, src/ba2_reader.cpp</files>
  <behavior>
    - Given Starfield v3 `CompressionMethod == 3` and a compressed entry, metadata reports `compression_state::lz4_block` and extraction returns raw LZ4 block decoded bytes.
    - Given Starfield v3 `CompressionMethod == 3` and a raw entry, metadata reports `compression_state::raw` and extraction returns raw bytes unchanged.
    - Given Starfield v3 default/zero compression method and a compressed entry, metadata reports `compression_state::deflate` and extraction uses deflate.
    - Given compressed Starfield v3 metadata with an unsupported compression method, extraction fails with `unsupported_format` or `malformed_archive` and sink remains empty.
  </behavior>
  <implementation>Extend header parsing to v3 header size 36 and `summary.compression_method = le_u32(header, 32)`. Resolve compressed-entry state as `lz4_block` only when format is Starfield BA2, version is v3, `PackedSize != 0`, and `compression_method == 3`; otherwise compressed entries remain deflate for supported methods. Let `resolve_payload_codec` reject unsupported lz4-block routes; add parser/extraction validation for unsupported BA2 compression method values if needed to produce a structured failure before writes.</implementation>
</feature>
