  <behavior>
    - Given generated FO4 BA2 GNRL v1/v7/v8 bytes with two entries and a FileTableOffset name table, `open_ba2` returns `archive_format::fallout4_ba2`, matching version, subtype `GNRL`, file count, normalized sorted paths, and expected metadata.
    - Given generated Starfield v2 BA2 GNRL bytes, `open_ba2` accounts for the extended 32-byte header, preserves version and file table offset in `archive_summary`, and returns expected entries.

  </behavior>
