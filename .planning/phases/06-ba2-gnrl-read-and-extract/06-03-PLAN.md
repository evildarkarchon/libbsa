<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| metadata -> source payload read | Parsed offsets and sizes control bounded reads from untrusted archive bytes. |
| compressed bytes -> codec dispatcher | Untrusted compressed payloads cross into libdeflate through the existing dispatcher. |
| decoded bytes -> caller sink | Decoded output is written to caller-owned `byte_sink`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-06 | Tampering/Denial of Service | payload range validation | mitigate | Validate `offset + stored_size` with checked addition and source size before allocation/read; fail with `malformed_archive`. |
| T-06-07 | Tampering | deflate route | mitigate | Use `resolve_payload_codec` and `decompress_payload` with exact `metadata.size`; no fallback codecs and no BSA embedded-prefix read. |
| T-06-08 | Tampering | GNRL path extension handling | accept | GNRL `.dds` entries are ordinary in-scope payloads; no disk extraction policy or DX10 reconstruction happens in this library phase. |
</threat_model>
