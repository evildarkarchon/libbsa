## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted BA2 tables -> parser allocations | Header counts and lengths control vector/string allocation. |
| untrusted names -> normalized paths | Archive names may contain traversal or absolute path syntax. |
| parsed ranges -> extraction reads | Offsets and stored sizes control source reads and sink writes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-12 | Tampering | truncated header/record/name table | mitigate | Exact bounded reads with `malformed_archive` failures and tests for each truncation class. |
| T-06-13 | Denial of Service | unchecked count/length allocation | mitigate | Checked multiplication/addition and size_t conversion before vectors/strings are allocated. |
| T-06-14 | Tampering | path traversal in BA2 names | mitigate | Normalize archive paths and reject absolute/traversal names as malformed parser input. |
| T-06-15 | Denial of Service | offset + size overflow | mitigate | Checked-add range validation before reads; failures occur before sink writes. |
</threat_model>
