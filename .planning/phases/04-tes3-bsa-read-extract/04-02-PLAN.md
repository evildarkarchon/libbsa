## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| archive prefix bytes→format detector | Untrusted bytes choose parser family and metadata defaults. |
| public metadata→consumer code | Public field names and offset meaning must not mislead consumers into unsafe seeks. |
| detector result→open dispatch | Misrouting TES3 bytes into TES4 parser can produce incorrect validation or error semantics. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-04-06 | Tampering | `entry_metadata::payload_offset` docs | mitigate | Doxygen states archive-absolute semantics for all variants; raw TES3 offsets remain manifest/test-only. |
| T-04-07 | Elevation of Privilege | public API boundary | mitigate | No TES3 private parser objects, TES5Edit symbols, dependency types, or `std::filesystem::path` archive keys are exposed. |
| T-04-08 | Denial of Service | open dispatch | mitigate | Variant-aware dispatch prevents attempting TES4-family parsing over TES3 table bytes. |
</threat_model>
