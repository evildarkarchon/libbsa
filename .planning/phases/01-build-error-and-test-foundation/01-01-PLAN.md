## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Developer workstation → vcpkg/CMake dependency graph | Configure step resolves third-party packages declared by the repository. |
| Repository source lists → build output | CMake source declarations decide what code is compiled and installed. |
| TES5Edit reference submodule → libbsa implementation | Read-only reference material must not cross into compiled or staged libbsa code. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-01-04 | Elevation of Privilege | Build foundation | accept | No executable application, privileged operation, parser, archive extraction, or network surface is introduced in this plan; no high-severity ASVS L1 threat applies. |
