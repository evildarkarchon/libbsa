<feature>
  <name>TES4-family compressed and embedded payload writer</name>
  <files>src/bsa_writer.cpp, tests/bsa_writer_tests.cpp</files>
  <behavior>
    - v103/v104 compressed entries extract through deflate and v105 compressed entries extract through LZ4-frame.
    - Native size field toggle bit is `archive_default_compressed XOR entry_is_compressed`; callers never set raw high-bit flags directly.
    - Embedded-name output is off by default; when enabled it sets `ARCHIVE_EMBEDNAME`, prefixes each payload with one-byte length plus the full entry archive path/name bytes in the exact format the existing reader skips, and extraction returns original payload.
    - Unsupported compression or malformed embedded-name requests fail during planning with structured errors and no sink writes.
    - Dedup enabled shares only exact byte-identical post-policy native stored payloads, including embedded-name and compression prefixes.
  </behavior>
  <implementation>Build native payloads as `[embedded len+full entry archive path/name bytes?][uncompressed u32 if compressed][compressed/raw bytes]`, choose deflate for v103/v104 and LZ4-frame for v105 through existing codec dispatch, compute BSA XOR size flags, and group dedup by exact native payload bytes after policy resolution.</implementation>
</feature>
