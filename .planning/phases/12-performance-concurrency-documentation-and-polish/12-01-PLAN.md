```cpp
class payload_sink {
 public:
  virtual ~payload_sink() = default;
  virtual result<std::size_t> write(std::span<const std::byte> bytes) = 0;
};

class archive_reader {
 public:
  [[nodiscard]] result<void> extract(std::string_view path, payload_sink& sink) const;
  [[nodiscard]] result<std::vector<std::byte>> extract_bytes(std::string_view path) const;
};
```

New public contract to implement:
```cpp
struct bulk_extract_options {
  std::uint32_t worker_count{1U};
};

struct bulk_extract_request {
  std::string path;
};

class bulk_extract_sink_factory {
 public:
  virtual ~bulk_extract_sink_factory() = default;
  virtual result<std::unique_ptr<payload_sink>> create(std::string_view path,
                                                       const entry_metadata& entry) = 0;
};

struct bulk_extract_entry_result {
  std::string path;
  std::optional<entry_metadata> entry;
  std::optional<error> failure;
  [[nodiscard]] bool succeeded() const noexcept;
};

[[nodiscard]] result<std::vector<bulk_extract_entry_result>>
archive_reader::extract_entries(std::span<const bulk_extract_request> requests,
                                bulk_extract_sink_factory& sink_factory,
                                bulk_extract_options options = {}) const;
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller -> archive_reader::extract_entries | Untrusted request paths and worker_count enter the public API. |
| archive bytes -> extraction workers | Archive-controlled offsets and sizes drive payload reads and decompression. |
| libbsa worker -> caller sink factory/sink | Caller code executes during extraction and may fail or be non-thread-safe. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01-01 | D | `bulk_extract_options::worker_count` | mitigate | Reject `worker_count == 0U` with `error_code::invalid_argument` and do not provide auto worker selection per D-02/D-09. |
| T-12-01-02 | T/D | `bulk_extract_sink_factory` and `payload_sink` | mitigate | Require one sink per entry, record partial writes as `io_error`, and never mark a partial sink entry successful per D-03/D-06. |
| T-12-01-03 | D | compressed extraction buffers | mitigate | Preserve exact-size decompression and per-entry/per-chunk allocation guards; add policy tests for D-14/D-15. |
| T-12-01-04 | R/T | parallel result aggregation | mitigate | Store results by original request index, not completion order, and continue independent entries after per-entry failures per D-04/D-05. |
</threat_model>
