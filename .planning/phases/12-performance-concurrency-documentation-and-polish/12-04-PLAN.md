<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DDS/source files -> BA2 writers | Caller-controlled disk files become archive payloads. |
| BA2 compression workers -> prepared records | Parallel workers produce stored payloads and chunk records. |
| writer temp files -> destination path | Publish and rollback protect caller-owned outputs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-04-01 | D | BA2 GNRL/DX10 disk sources | mitigate | Stream raw disk payloads and bound compressed buffers to per-entry/per-chunk data. |
| T-12-04-02 | T | DX10 source snapshotting | mitigate | Store writer-owned temp snapshots/subresource payloads so later source mutation cannot affect output without retaining whole DDS vectors. |
| T-12-04-03 | T/D | parallel compression | mitigate | Store results by deterministic entry/chunk index and perform offset assignment after worker completion. |
| T-12-04-04 | T/R | publish rollback | mitigate | Preserve unique temp directory, backup, and rollback semantics; verify failures in worker_count paths. |
</threat_model>
