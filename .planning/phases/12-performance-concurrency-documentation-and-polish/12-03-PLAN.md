## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host source files -> writer | Caller-controlled disk files are read and packed. |
| writer workers -> shared preparation state | Parallel compression writes prepared records by index. |
| writer temp archive -> output path | Safe publish and overwrite rollback protect caller destinations. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-03-01 | D | disk-backed source reads | mitigate | Use fixed scratch buffers for raw disk-backed payload streaming and typed I/O errors for short/bad reads. |
| T-12-03-02 | T | parallel TES4 compression | mitigate | Store prepared entries by deterministic index, sort after worker completion, and preserve offset/dedupe semantics. |
| T-12-03-03 | T/R | safe publish | mitigate | Preserve unique temp, no-replace, backup, and rollback behavior; add failure tests for worker_count paths. |
| T-12-03-04 | I | public API boundary | mitigate | Keep all helper state private and preserve forbidden-token public header scans. |
</threat_model>
