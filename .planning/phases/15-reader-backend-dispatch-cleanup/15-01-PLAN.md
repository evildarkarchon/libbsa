<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller -> `archive_reader::open` | Untrusted host-path text and archive bytes enter format detection and parser selection here. |
| facade -> backend table | Public reader methods cross into family-specific lookup and extraction callbacks selected at open time. |
| backend extraction -> caller sink | Extracted bytes cross from archive payload readers into caller-owned sinks that may partially accept data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-01 | T | `src/archive.cpp` open-time backend selector | mitigate | Keep all family detection and parser choice centralized in `archive_reader::open`; backend selection must be derived from the same detected metadata that already gates parser choice, with runtime regression tests covering TES3, TES4, BA2 GNRL FO4, BA2 GNRL Starfield v3, and BA2 DX10. |
| T-15-02 | T | `src/archive.cpp` lookup/extract facade | mitigate | Preserve current `normalize_archive_path`-driven `find()` semantics and shared `not_found` translation; implement `contains()` as `find()` + `has_value()` so malformed archive paths do not collapse into false negatives. |
| T-15-03 | T | payload extraction reopen path | mitigate | Continue passing only stored `detail::host_file_path` into backend extraction callbacks and add comments/tests that forbid reopening from raw UTF-8 caller text after open succeeds. |
| T-15-04 | D | caller sink interaction during extraction | mitigate | Keep existing partial-write handling and run focused `bulk_extraction` regression coverage alongside the new dispatch suite so backend rewiring cannot silently treat partial sink acceptance as success. |
| T-15-05 | R | future maintenance drift in `src/archive.cpp` | mitigate | Add a negative method-scoped source-policy test that fails if `entries`, `find`, `contains`, `extract`, `extract_bytes`, or `extract_entries` regain family-branching tokens outside the centralized seam. |
</threat_model>
