<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller bytes → `byte_source::read_at` | Untrusted offsets and requested sizes cross into bounded read logic. |
| Producer bytes → `byte_sink::write` | Untrusted byte spans cross into caller-provided sink storage. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | T/D | `memory_source::read_at` | mitigate | Check `offset <= size` and `count <= size - offset` before copying; return `error_code::io_failure` on invalid ranges. |
| T-02-02 | I | `include/libbsa/io.hpp` | mitigate | Public header includes only standard/libbsa-owned types and does not expose host file paths, dependency handles, or TES5Edit types. |
</threat_model>
