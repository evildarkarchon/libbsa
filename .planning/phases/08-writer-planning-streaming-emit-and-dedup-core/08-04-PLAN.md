  </behavior>

Entry table serialization must be byte-for-byte the same sizing contract used by Plan 02: fixed numeric fields (`data_region_id`, `offset`, `size`, `stored_size`, path length) plus variable normalized path bytes for every entry. Return the first sink failure unchanged. Do not retain sink references after return.</implementation>
