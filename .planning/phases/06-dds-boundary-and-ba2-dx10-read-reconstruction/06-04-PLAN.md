- D-01: The parser materializes BA2 DX10 texture metadata into the existing `entry_metadata::texture` optional.
- D-02: Parsed metadata populates only the minimal public value structs planned for this phase.
- D-03: Parsed DX10 format values are exposed as raw numeric DXGI ids.
- D-04: Parsed entries expose dimensions, mip count, array size, and `is_cubemap` explicitly.
- D-05: Parsed entries expose public per-entry chunk lists with archive-absolute payload offsets, stored/raw sizes, mip ranges, and compression route.
- D-06: Parsed DX10 `entry_metadata::raw_size` is the reconstructed DDS byte size including the header.
- D-07: Parser preserves archive-derived raw DX10 fields such as `unknown_tex` and `cube_maps_raw` where they affect reconstruction or compatibility evidence.
- D-08: Parser populates texture metadata only for BA2 DX10, leaving existing BSA/GNRL behavior unchanged.
- D-16: Open-time parser validation rejects truncated tables, invalid spans, inconsistent counts/sizes, gaps, duplicates, or impossible coverage with `format_error`.
- D-19: DX10 lookup preserves BA2 GNRL canonical lowercase `/` keys, `original_path`, duplicate canonical rejection, and `not_found` behavior.
- D-29: The existing `archive_reader` facade remains the public entry point for open, metadata, entries, find/contains, and later extraction.
- D-31: Compression routing metadata is parsed from archive/chunk fields, including Starfield v3 method `3`, never inferred from file extension or path spelling.
</decision_coverage>
