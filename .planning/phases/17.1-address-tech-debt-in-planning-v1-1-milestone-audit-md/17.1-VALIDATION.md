## Sampling Rate

- **After every task commit:** Run `ctest --preset windows-msvc-debug-static --output-on-failure -R "host_path_correctness_boundary|archive_reader_dispatch|host_file|host_file_path"`.
- **After every plan wave:** Run `ctest --preset windows-msvc-debug-static --output-on-failure`.
- **Before `/gsd-verify-work`:** Run focused Debug and focused MSVC AddressSanitizer lanes.
- **Max feedback latency:** No 3 consecutive implementation tasks should pass without a focused automated CTest run.
