<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller GNRL entries → planner | Untrusted archive paths, sizes, and payload bytes become native BA2 tables. |
| planner → native 32-bit/16-bit fields | Layout sizes and name lengths can overflow/truncate. |
| finalizer → byte_sink | Caller-owned sink can fail during table or payload writes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-04 | Tampering | `plan_ba2_gnrl_write` | mitigate | Normalize archive paths and reject duplicate normalized paths before table creation. |
| T-10-05 | Tampering / DoS | GNRL layout arithmetic | mitigate | Use checked add and integer-fit helpers for header, record table, name table, payload offsets, `uint16` name lengths, `uint32` packed/unpacked sizes, and total archive size. |
| T-10-06 | Repudiation | `finalize_ba2_write` | mitigate | Return first `byte_sink::write` error unchanged and perform no recomputation during finalization. |
</threat_model>
